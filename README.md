# Avothar_Farms_and_Stays_Booking_System
A full-stack accommodation booking website developed using Python Flask, MySQL, and Bootstrap 5. It allows users to explore villas, farmhouses, and houses, view rental prices, check availability, make bookings, and download PDF booking receipts. Includes admin dashboard, property management, booking management, and revenue reports.
